# ASSYLUM

Браузерная хоррор-игра с видом сверху: побег из психбольницы №6. Сделана на Phaser 3, TypeScript
и Vite; мультиплеер работает напрямую между браузерами через PeerJS.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка в dist/
npm test         # юнит-тесты (vitest)
npm run check    # всё перед пушем: типы + тесты + сборка
npm run assets   # новые картинки из art/ → public/assets/*.webp + манифест
```

Мультиплеер по умолчанию использует публичный сервер PeerJS. Чтобы подключить свой, задай
переменную `VITE_PEER_SERVER`:

```bash
VITE_PEER_SERVER=localhost:9000 npm run dev   # или https://peer.example.com/path
```

## Управление

| Клавиша | Беглец | Охотник (Foxmind) |
|---|---|---|
| WASD / стрелки | шаг | шаг |
| Shift / C | бег / тихий шаг | бег / тихий шаг |
| Мышь | куда светит фонарик | куда смотрит |
| E (или F) | действие: спрятаться, терминал, щиток, дверь | обыскать укрытие, дверь |
| R / V | фонарик / режим луча | вспышка |
| 1 / 2 / 3 | предметы из инвентаря | — |
| Пробел | задержать дыхание в укрытии | — |
| Q | свист (Yoko) | — |
| Tab / Esc | сменить наблюдаемого / выход | |

## Устройство кода

Каждая вещь живёт в одном месте. Если нужно что-то поменять — вот где искать:

| Папка | Что внутри |
|---|---|
| `src/core/` | размеры мира, геометрия, seed-рандом, шина событий, настройки, музыка |
| `src/data/` | **все цифры и контент**: персонажи, сложность, баланс, комнаты, манифест ассетов |
| `src/ui/` | **дизайн-система**: `theme.ts` (цвета, шрифты, слои), `components.ts` (кнопки, панели, переключатели, сообщения) |
| `src/world/` | уровень: генератор по seed, сетка (путь, видимость, прямая видимость — одна реализация), коллизии |
| `src/entities/` | `Actor` — любой персонаж: игрок, бот, охотник, босс, сетевой игрок |
| `src/ai/` | мозги ботов, охотника и босса: органы чувств, память, запах, выбор целей |
| `src/systems/` | механики: ключи и выход, питание, двери и терминалы, предметы, укрытия, выносливость, свет, видимость, шум, раунд, ввод, сеть |
| `src/game/` | общий контекст раунда (`World`), фабрика персонажей, правила конца раунда |
| `src/net/` | PeerJS-сессия и типы сетевых сообщений |
| `src/render/` | отрисовка: запекание мира, шейдер света, камера, заглушки текстур, загрузка ассетов |
| `src/scenes/` | экраны: загрузка, меню, выбор, лобби, настройки, игра, HUD, итог |
| `tests/` | юнит-тесты генератора, сетки и правил раунда |
| `art/` | исходники картинок (PNG); в игру идут их сжатые копии из `public/assets/` |
| `scripts/assets.mjs` | конвейер ассетов: обрезка, уменьшение, WebP, манифест |

Правила: цвета и шрифты берутся только из `ui/theme.ts`, элементы интерфейса — только из
`ui/components.ts`; механика меняет состояние в своей системе и сообщает об этом событием
(`keyCollected`, `runnerCaught`…), а HUD, эффекты и сеть на эти события подписаны.
